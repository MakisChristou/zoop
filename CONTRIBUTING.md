# Contributing

Read [AGENTS.md](AGENTS.md) for architecture and conventions, and the README for
setup and checks. Discuss changes to behavior or data handling before implementing
them. Keep fixes small and include a regression test for data or security changes.

Use synthetic fixtures. Never commit tokens, private configuration, health captures,
local database files or generated screenshots. The approved README images are the
only exception. Report security issues using [SECURITY.md](SECURITY.md).

Submit changes against main with the checks you ran and their results. Contributions
are under the repository's MIT license; third-party notices remain applicable.
