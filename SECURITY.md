# Security

Do not post credentials, health recordings or exploitable security details in public
issues. Report privately through GitHub's **Security → Report a vulnerability**
when enabled. If unavailable, open an issue asking for a private contact without
including the vulnerability details; wait for a private channel before sharing them.

This project is a self-hosted developer alpha. Use HTTPS for public access; HTTP
is intended for trusted networks or a VPN. Keep the database private, update
regularly and verify backups. No independent security audit is claimed.
Only the current main branch receives fixes until versioned releases are established.
